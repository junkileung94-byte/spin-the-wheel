# Sounds

Generated on Higgsfield (Google Veo 3.1 Fast, native audio) on 2026-10-28, then trimmed,
faded and level-matched with ffmpeg. Only the audio of each clip is used.

| File | Used for | Source clip prompt (short) |
| --- | --- | --- |
| `spin.wav` | Spin starts | Hand spins a prize wheel: whoosh, then clicking pegs |
| `tick.wav`, `tick2.wav` | Each slice passing the pointer | Single clicks from the same clip |
| `win.wav` | Winner | Bright bell chime with a sparkling shimmer |
| `bubbles.wav` | Under the winner chime | Underwater burst of bubbles rushing upward |
| `pop1.wav` … `pop4.wav` | Each bubble popping | Close-up soap bubbles popping one by one |

To use your own sounds, replace a file with a short WAV of the same name (mono, 44.1 kHz works
everywhere, including OBS). If a file is missing the app falls back to a built-in synth sound.
